# 提示词 C · 四要素 + 链式推理（R-C-T-F + CoT）

> 同时使用「角色·上下文·任务·格式」四要素，并要求“先思路、后实现、再验证”。
> 这是得到本目录 `sort_students.py` 参考实现所用的提示词。

```text
角色：你是一名注重可读性与健壮性的资深 Python 工程师。

上下文：students 是 list[dict]，每个元素含 name(str) 与 score(int)。

任务：实现函数 sort_students(students)：
  - 按 score 降序排序；score 相同时按 name 升序；
  - 必须稳定排序；不得修改原列表（返回新列表）；
  - 对缺少 name/score 字段的元素抛出 ValueError。

格式要求：
  1) 先用 2~3 句话说明你的排序键设计与稳定性思路；
  2) 再给出带类型注解与文档字符串的完整实现；
  3) 最后给出 1 个使用示例，并说明时间复杂度。
```

## 效果
- 四要素让需求“无歧义”，CoT 让模型先暴露思路、便于人工审查。
- 产出通常一次到位：键设计 `(-score, name)`、稳定、不可变、含边界处理。
- 这正是“把想法翻译成可验证的规格”的范例。
