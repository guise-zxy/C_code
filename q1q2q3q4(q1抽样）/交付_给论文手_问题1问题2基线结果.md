## 3. 问题1论文表述建议

设从一批零配件中随机抽取 `n` 件，其中次品数为 `X`，则：

```text
X ~ Bin(n,p)
```

其中 `p` 为该批零配件的真实次品率。标称次品率为：

```text
p0 = 0.10
```

为控制检验功效，引入不可接受次品率：

```text
p_bad = 0.15
```

采用双阈值判定规则：

```text
X <= a：接收
a < X < r：证据不足
X >= r：拒收
```

通过精确二项分布搜索，得到：

```text
n = 368
a = 29
r = 47
```

因此具体判定规则为：

```text
X <= 29：接收该批零配件；
30 <= X <= 46：证据不足，建议继续抽样或转全检；
X >= 47：拒收该批零配件。
```

关键概率为：

```text
P_0.10(接收) = 0.0993944299
P_0.10(拒收) = 0.0496448526
P_0.15(拒收) = 0.9000671839
P_0.15(不拒收) = 0.0999328161
```

最小性验证：

```text
n = 367 时，P_0.15(拒收) = 0.8963084201 < 0.90
```

因此，`n=368` 是当前约束下的最小固定样本量。

## 5. 问题2论文表述建议

对生产过程中的四个决策进行编码：

```text
d1：是否检测零配件1
d2：是否检测零配件2
df：是否检测成品
dr：是否拆解不合格成品
```

其中 `d=1` 表示执行该操作，`d=0` 表示不执行。

共枚举：

```text
2^4 = 16 种静态策略
```

对表1中的6种情形分别计算每种策略下的期望成本和期望利润。

经济核算口径：

```text
以最终交付1件合格品为核算单位；
市场售价只计算一次；
换货不产生新的销售收入；
换货仍计调换损失；
检测默认完全准确；
拆解后的零件保留其质量状态。
```

程序同时比较了两种回流检测口径：

```text
口径1：已知合格回流件不复检；
口径2：只要设置检测，每轮均复检。
```

两种口径下，六种情形的最优策略均未发生变化，仅期望成本和期望利润数值发生变化。

目标函数：

```text
期望利润 = 市场售价 - 最终交付1件合格品前产生的全部期望成本
```

## 6. 问题2不可行策略说明

枚举结果中存在不可行策略。

当：

```text
dr = 1
且 d1 或 d2 至少有一个为 0
```

即选择拆解不合格成品，但至少有一种零配件不检测时，可能出现以下情况：

```text
某个坏零件未被检测出来；
该坏零件进入装配环节，导致成品不合格；
不合格成品被拆解后，坏零件继续回流；
由于该类零件仍不检测，坏零件会被再次用于装配；
于是存在正概率永远无法交付合格品。
```

因此，这类策略不应视为高成本策略，而应判定为不可行策略。

当前枚举结果：

```text
总策略数：96
可行策略：60
不可行策略：36
```

## 8. 问题2结果解释建议

```text

```

```text
在情况4中，调换损失较高且成品检测成本较低，因此最优策略增加了成品检测，
以避免不合格成品流入市场带来较高调换损失。
```

```text
在情况5中，零配件1检测成本较高，而零配件2检测成本较低，因此最优策略只检测零配件2。
```

```text
在情况6中，零配件和成品次品率较低，而拆解费用很高，因此最优策略为不检测、不拆解，
通过承担较小的市场调换风险获得更高期望利润。
```
