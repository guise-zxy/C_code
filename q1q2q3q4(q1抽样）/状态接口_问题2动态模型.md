# 问题2动态模型状态接口

## 1. 目的

本文档用于约束后续状态依赖动态模型，避免程序读取企业实际不可观测的零件真实质量。

当前问题2静态递归基线仍保留；动态模型若继续实现，必须遵守本接口。

## 2. 企业可观测信息

企业在生产过程中只能观察到：

```text
1. 当前生产阶段；
2. 零件来源：新购或拆解回流；
3. 零件是否已经被准确检测确认合格；
4. 零件检测结果：合格或不合格；
5. 成品检测结果：合格或不合格；
6. 是否发生市场退货；
7. 已发生的采购、检测、装配、拆解、调换成本。
```

企业不能直接观察未经检测零件的真实质量。

## 3. 隐藏真实质量状态

对两零件情形，真实质量状态为：

```text
Z = (Z1, Z2)
Zi = 1 表示零件 i 真实合格；
Zi = 0 表示零件 i 真实不合格。
```

共有四种隐藏微状态：

```text
(1,1), (1,0), (0,1), (0,0)
```

该真实状态仅用于概率计算和后验更新，不能作为企业决策时直接读取的信息。

## 4. 联合 belief 表示

企业维护联合 belief：

```text
b(z1,z2) = P(Z1=z1, Z2=z2 | 当前可观测历史)
```

不能只保存两个边缘次品率。因为成品检测失败或市场退货会让两个零件质量在后验分布中产生相关性。

初始新购零件时：

```text
b(1,1) = (1-p1)(1-p2)
b(1,0) = (1-p1)p2
b(0,1) = p1(1-p2)
b(0,0) = p1p2
```

## 5. 状态更新

### 5.1 零件检测

若检测零件 i：

```text
检测合格：保留 Zi=1 的状态，并归一化 belief；
检测不合格：丢弃该零件，重新采购，直到得到允许进入装配的零件。
```

在检测完全准确的假设下，已检测合格且拆解后未损坏的零件为“已知合格”。

### 5.2 成品失败或市场退货

成品合格概率为：

```text
P(Y=1 | Z1,Z2) = (1-pf) * 1{Z1=1, Z2=1}
```

观察到成品失败后，按贝叶斯公式更新：

```text
b'(z1,z2)
= P(Y=0 | z1,z2) b(z1,z2)
  / sum_{u1,u2} P(Y=0 | u1,u2) b(u1,u2)
```

市场退货视为成品失败观测，同样更新联合 belief。

## 6. 允许动作

根据当前可观测状态，允许动作包括：

```text
1. 检测零件；
2. 替换检测出的不合格零件；
3. 装配成品；
4. 检测成品；
5. 直接销售成品；
6. 拆解不合格成品并回流零件；
7. 报废不合格成品并重新采购；
8. 对市场退货品承担调换损失后，选择拆解或报废。
```

动作选择只能依赖可观测历史和 belief，不能依赖隐藏真实质量标签。

## 7. 成本与收益

成本包括：

```text
采购成本；
零件检测成本；
装配成本；
成品检测成本；
拆解费用；
调换损失。
```

收益口径：

```text
最终成功交付一件合格品时，市场售价只计一次；
换货不产生第二次销售收入。
```

因此：

```text
期望利润 = 市场售价 - 最终成功交付前的全部期望成本
```

## 8. 吸收状态

唯一正常吸收状态：

```text
最终成功交付一件合格品。
```

报废、拆解、厂内发现不合格、市场退货都不是吸收状态，而是带成本的中间转移。

## 9. 不可行与死循环判定

允许生产过程重复多轮。

只有满足以下条件之一，才判定策略不可行：

```text
1. 最终成功交付概率小于 1；
2. 期望成本为无穷；
3. 流程可能进入无法退出的失败闭环。
```

不得通过人为限制循环次数来计算有限结果。

典型不可行情形：

```text
选择拆解不合格成品；
但至少一种零件不检测；
坏零件可能在拆解后无限回流并反复导致成品失败。
```

## 10. 当前主口径建议

在“检测完全准确、拆解不损坏零件”的假设下，建议正文主口径采用：

```text
已知合格回流件不复检。
```

理由：

```text
已知合格件再次检测没有新增信息，只增加成本。
```

“每轮复检”作为稳健性对照保留。
