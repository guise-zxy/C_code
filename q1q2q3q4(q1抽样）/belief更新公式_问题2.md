# 问题2 belief 更新公式

## 1. 隐藏质量状态

设两零配件真实质量为：

```text
Z = (Z1, Z2)
Zi = 1：零件 i 合格
Zi = 0：零件 i 不合格
```

隐藏状态空间为：

```text
S = {(1,1), (1,0), (0,1), (0,0)}
```

企业不能直接观察未经检测零件的真实质量，只能维护联合 belief：

```text
b_t(z1,z2) = P(Z1=z1, Z2=z2 | H_t)
```

其中 `H_t` 是截至时刻 `t` 的全部可观测历史。

## 2. 初始 belief

新购两个零件时，若零件1、零件2次品率分别为 `p1,p2`，且初始独立，则：

```text
b(1,1) = (1-p1)(1-p2)
b(1,0) = (1-p1)p2
b(0,1) = p1(1-p2)
b(0,0) = p1p2
```

## 3. 通用贝叶斯更新

若采取动作 `a_t` 后观察到结果 `o_{t+1}`，则：

```text
b_{t+1}(z1,z2)
= P(o_{t+1} | z1,z2,a_t) b_t(z1,z2)
  / sum_{u1,u2} P(o_{t+1} | u1,u2,a_t) b_t(u1,u2)
```

若分母为 0，说明该观测在当前 belief 与动作下不可能发生，程序应报错或阻断该分支。

## 4. 零件检测更新

检测完全准确。

### 4.1 检测零件1合格

观察 `O = {Z1=1}`：

```text
b'(z1,z2) =
  b(z1,z2) / P(Z1=1),  if z1=1
  0,                   if z1=0
```

其中：

```text
P(Z1=1) = b(1,1) + b(1,0)
```

### 4.2 检测零件1不合格

观察 `O = {Z1=0}`：

```text
b'(z1,z2) =
  b(z1,z2) / P(Z1=0),  if z1=0
  0,                   if z1=1
```

其中：

```text
P(Z1=0) = b(0,1) + b(0,0)
```

若不合格零件被丢弃并重新采购直到得到合格件，则新状态中零件1变为已知合格，零件2保留检测前后的条件后验：

```text
b_new(1,z2) = P(Z2=z2 | 检测到 Z1=0)
b_new(0,z2) = 0
```

零件2同理。

## 5. 成品质量观测更新

设 `pf` 为两个零件均合格时，装配后成品仍不合格的概率。

成品合格概率：

```text
P(Y=1 | z1,z2) = (1-pf) * 1{z1=1,z2=1}
```

成品不合格概率：

```text
P(Y=0 | z1,z2) = 1 - (1-pf) * 1{z1=1,z2=1}
```

## 6. 观察到成品合格

若成品检测合格，或销售后最终确认该件合格，则：

```text
b'(1,1) = 1
b'(1,0) = b'(0,1) = b'(0,0) = 0
```

同时流程进入“最终成功交付一件合格品”的吸收状态。

## 7. 观察到成品不合格

若成品检测不合格，或市场退货表示该成品不合格，则：

```text
b'(z1,z2)
= P(Y=0 | z1,z2) b(z1,z2)
  / sum_{u1,u2} P(Y=0 | u1,u2) b(u1,u2)
```

展开后：

```text
b'(1,1) = pf * b(1,1) / D
b'(1,0) = b(1,0) / D
b'(0,1) = b(0,1) / D
b'(0,0) = b(0,0) / D
```

其中：

```text
D = pf*b(1,1) + b(1,0) + b(0,1) + b(0,0)
```

该更新会使两个零件质量产生相关性，因此不能只保存两个边缘次品率。

## 8. 拆解回流

题目假设拆解不损坏零件，因此拆解后零件真实质量不变。

若成品失败后拆解：

```text
belief 先按“成品不合格”更新；
随后回流零件携带该后验 belief 进入下一轮生产。
```

若某零件此前已被检测确认为合格，则其状态保持已知合格。

## 9. 报废重购

若不合格成品报废，则本轮零件不再回流。

下一轮重新采购两个零件，belief 回到初始分布：

```text
b0 = ((1-p1)(1-p2), (1-p1)p2, p1(1-p2), p1p2)
```

## 10. 当前代码对应关系

当前静态递归基线中：

```text
initial_belief(case)      对应初始 belief；
condition_belief(...)     对应零件检测后的条件化；
condition_on_bad_product  对应成品失败后的贝叶斯更新；
set_part_good(...)        对应检测到坏件后丢弃并替换为已知合格件。
```
