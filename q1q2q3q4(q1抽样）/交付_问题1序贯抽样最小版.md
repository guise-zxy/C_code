# 问题1序贯抽样最小可运行版

本版本为 Q1 固定样本方案之外的改进方向，不修改已经冻结的 Q1 固定样本主模型。

## 1. 模型口径

```text
p0 = 10%
pbad = 15%
最大样本量 n_max = 368
每个阶段只输出：接收、继续抽样、拒收
总体概率核算方法：精确递推 / 动态规划
不使用蒙特卡洛近似
不直接套普通 Wald SPRT 后默认风险满足
```

采用的最小可行规则：

```text
不设置早接收；
从 n = 180 开始允许早拒收；
早拒收边界由 log likelihood ratio >= 4.4 给出；
n = 368 时使用最终固定样本边界：
  缺陷数 <= 29：接收
  缺陷数 >= 47：拒收
  30 <= 缺陷数 <= 46：未决
```

## 3. 约束验证

精确递推结果：

```text
p = 10%：
  最终接收概率 = 0.0993944299 <= 0.10
  最终拒收概率 = 0.0499500587 <= 0.05
  未决概率 = 0.8506555114
  ASN = 367.3161

p = 15%：
  最终接收概率 = 0.0000266117
  最终拒收概率 = 0.9003309986 >= 0.90
  未决概率 = 0.0996423897
  ASN = 288.8771
```

三项约束均通过。

## 4. 与固定抽取368件比较

## 5. 建议表述

```text
该序贯方案在三项风险与功效约束下可行。
但平均检测量改善主要出现在实际次品率高于不可接受水平附近；
在 p = 10% 附近几乎不能减少检测量。
因此不替代 Q1 固定样本主模型，更适合作为“企业后续可采用的序贯抽样改进方案”。
```
