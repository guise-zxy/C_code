# 问题1双边序贯抽样最小范围尝试

本次只在 Q1 序贯改进方向上做最小范围尝试，不修改 Q1 固定样本主模型，也不修改 Q2-Q4。

## 1. 固定口径

```text
p0 = 0.10
pbad = 0.15
n_max = 368
终端规则保持固定样本口径：
  n=368时，X <= 29 接收；
  30 <= X <= 46 未决；
  X >= 47 拒收。
```

n < 368 时使用累计似然比：

```text
log Lambda_n = log[L(p=0.15) / L(p=0.10)]
```

双边早停规则：

```text
log Lambda_n <= A：提前接收；
log Lambda_n >= B：提前拒收；
中间：继续抽样。
```

## 2. 搜索结果

论文手给出的 A≈-8.94 被作为初值测试，结果可行。

```text
A = -8.94
B = 4.32
```

注意：该参数只是当前小范围搜索下的可行改进方案，不表述为全局最优。

## 3. 精确递推验证

```text
P_p=0.10(最终接收) = 0.0999980897 <= 0.10
P_p=0.10(最终拒收) = 0.0499950372 <= 0.05
P_p=0.15(截至368最终拒收) = 0.9003696290 >= 0.90
```

三项约束均通过。
