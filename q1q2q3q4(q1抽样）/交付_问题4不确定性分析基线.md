## 2. 样本数据假设

题目没有给出各次品率的原始样本量和检测次品数。

因此当前采用建模假设：

```text
样本量 n ∈ {100, 368, 400, 1000}
样本次品数 x = round(n * 表中次品率)
点估计 p_hat = x / n
```

必须注意：

```text
这些样本量和次品数是建模假设，不是题目给出的数据。
```

主场景为：

```text
n = 368
```

## 3. 置信区间

每个次品率均计算：

```text
点估计；
Clopper-Pearson 精确置信区间下限；
Clopper-Pearson 精确置信区间上限。
```

置信水平：

```text
95%
```

口径说明：

```text
各参数分别构造边际95% Clopper-Pearson精确置信区间；
再将这些边际区间组成不确定性区间盒。
```

不要写成：

```text
所有参数同时具有95%覆盖率。
```

输出文件：

```text
problem_b/results/q4/q4_q2_ci_inputs.csv
problem_b/results/q4/q4_q3_ci_inputs.csv
```

## 4. 稳健决策模型

对每个固定策略，计算其在不利次品率场景下的期望利润。

单调性口径：

```text
递归成本结构给出理论单调性；
Q2：对每种策略检查3个参数的8个区间端点组合，并比较所有可比端点对；
Q3：对每种策略逐个参数升高到置信上限，检查期望利润是否不会增加；
程序端点及逐参数检查作为数值验证。
```

因此，若理论单调性和数值验证均通过，则置信上限组合是区间盒内的最坏情形。

稳健目标为：

```text
选择最坏情况下期望利润最高的策略。
```

输出文件：

```text
problem_b/results/q4/q4_monotonicity_checks.csv
```

当前检查结果：

```text
Q2六种情形、Q3在 n=100,368,400,1000 下的单调性检查均通过。
```

Q3单调性说明：

```text
在装配树递归成本中，次品率升高会降低单次成功概率或增加达到已知合格状态前的期望尝试次数；
在成本参数非负的条件下，固定策略的期望成本不会下降，因此期望利润不会增加。
递归成本结构给出理论单调性，程序端点及逐参数检查作为数值验证，因此置信上限组合是区间盒内的最坏情形。
```

## 7. 不同样本量敏感性

已比较：

```text
n = 100
n = 368
n = 400
n = 1000
```

总体规律：

```text
样本量越大，Clopper-Pearson置信区间越窄；
最坏情况下的期望利润提高；
稳健策略更接近点估计最优策略。
```

Q3中：

```text
n=100 时，稳健策略发生变化；
n=368、n=400 和 n=1000 时，稳健策略与点估计最优策略一致。
```

Q2中：

```text
情形5、情形6在四个样本量下均表现出稳健策略严格切换；
说明这两个情形对次品率不确定性较敏感。
```

样本量解释：

```text
样本量敏感性中，次品数取整会同时改变点估计；
因此不同样本量之间的差异不完全由置信区间宽度造成。
n=400 作为补充对照，因为表中5%、10%、20%均可被400整除，点估计与表中名义值一致。
```

## 10. 论文表述建议

建议写法：

```text
由于题目未给出抽样检测的原始样本量和次品数，本文将样本量和检测次品数作为可调参数。
主场景设样本量为368，检测次品数取round(368p)，其中p为表中给定次品率。
基于精确二项分布构造Clopper-Pearson置信区间，并在置信区间上界构成的不利情形下进行稳健期望利润最大化。
```

避免写法：

```text
题目给定样本量为368；
题目给定检测次品数为round(368p)；
所有置信上限天然就是最坏情况。
```

最后一句必须改成：

```text
递归成本结构给出理论单调性，程序端点及逐参数检查作为数值验证，因此置信上限组合是区间盒内的最坏情形。
```
