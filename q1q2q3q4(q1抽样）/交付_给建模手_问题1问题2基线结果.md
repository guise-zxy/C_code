## 4. 问题2建模口径

当前程序同时输出两种口径：

```text
no_retest_known_good：已知合格回流件不复检；
retest_known_good：只要设置检测，每轮均复检。
```

共同口径：

```text
检测完全准确；
最终交付1件合格品为核算单位；
售价只计算一次；
换货不产生新销售收入；
换货仍计调换损失；
报废后重新购买并开始下一轮生产；
拆解回流零件保留质量后验状态；
市场次品率只作为指标报告，不加入硬约束。
```

策略变量：

```text
d1：是否检测零配件1
d2：是否检测零配件2
df：是否检测成品
dr：是否拆解不合格成品
```

目标函数：

```text
最大化最终交付1件合格品的期望利润

期望利润 = 市场售价 - 最终交付前产生的全部期望成本
```

## 5. 问题2策略可行性

每种复检口径下，表1六种情形共枚举：

```text
6 × 16 = 96 个策略
```

两种口径合计输出：

```text
总策略记录：192 行
```

不可行策略的共同特征：

```text
dr = 1，且 d1 或 d2 至少有一个为 0。
```

不可行原因：

```text
若某个坏零件没有被检测出来，成品会不合格；
若此时选择拆解，不合格成品拆解后坏零件会继续回流；
由于该零件后续仍不检测，坏零件会被反复用于装配；
因此存在正概率永远无法交付合格品。
```

所以这些策略不是“成本较高”，而是应判定为不可行。
